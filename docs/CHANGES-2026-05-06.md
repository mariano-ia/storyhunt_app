## Tracking destinations (current)

Each user event hits up to 4 destinations:
1. **Meta Pixel** (client) + **Meta CAPI** (server, dedup by event_id)
2. **GA4** (client gtag) + **GA4 Measurement Protocol** (server, dedup by event_id)
3. **PostHog** (client posthog.capture + server posthog-node)
4. **Firestore `events`** collection (our own log, has `sent_to_meta/ga4/posthog` flags)
